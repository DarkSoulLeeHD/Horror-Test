## 📌 SYNOPSIS & HIGH CONCEPT

**Projekt Krasny Bor** ist ein düsteres, unerbittliches 1–4 Spieler Open-World Koop-Horrorspiel auf dem Windows PC. 

Oktober 1986: In einem abgeriegelten Waldgebiet im Nordwesten Russlands bricht ein uralter, ektoplasmatischer Fluch über ein sowjetisches Militär-Forschungsareal herein. Ihr infiltriert die 16 km² große Sperrzone als verbliebenes Sanierungs- und Bergungsteam. Euer Ziel ist es, drei versiegelte arkan-biologische Altäre in der Welt zu triangulieren, zu reinigen und vor dem endgültigen Vorrücken der tödlichen Nekrose-Front mit den Reliquien-Proben zu exfiltrieren.

## 💀 CORE FEATURES

### 1. 100% Diegetisches UI & Taktische PC-Steuerung
Keine fliegenden Icons, keine roten Feind-Silhouetten, keine Fadenkreuze oder Lebensbalken:
* **Physischer Rucksack (`[Tab]`):** Die Figur kniet sich ab und breitet den Rucksack auf den Beinen aus. Items werden in Echtzeit per Maus gegriffen. Das Spiel pausiert nicht.
* **Manuelle Magazin-Inspektion (`[R]` halten):** Der Spieler zieht das Magazin aus der Waffe und schätzt die verbleibenden Patronen visuell.
* **Wund-Inspektion (`[T]`):** Ärmel hochkrempeln und Blutungen mit echten Tourniquets und Kompressen abbinden.
* **Orientierung (`[M]` & `[C]`):** Physische Papierkarte in der Hand, beleuchtet von der Taschenlampe, kombiniert mit einem analogen Marschkompass.

### 2. Psychologischer Koop & Stimmen-Mimikry (Anti-Clowning)
Multiplayer senkt nicht die Angst, sondern verstärkt das Misstrauen:
* **Stimmen-Mimikry (MetaSounds):** Die Monster-KI zeichnet 3-sekündige Sprachfetzen der echten Spieler auf und spielt sie im Nebel verzerrt als Köder-Hilferufe ab.
* **Asymmetrische Sanity-Desynchronisation:** Sinkt die geistige Stabilität von Spieler A, sieht er Phantome, blutende Wände und vernagelte Türen, die für Spieler B nicht existieren.
* **Erzwungene Isolation:** Panikfallen und Einstürze trennen das Team in der Dunkelheit.

### 3. Sound-basierte Monster-KI & Live-Mikrofon-Tracking
* **AIPerception Hearing Sense:** Die KI reagiert auf Schleichen (0.1), Gehen (0.4), Sprinten (1.2) und Barrikaden (1.8).
* **Live-Mikrofon-Tracking:** Der RMS-Lautstärkepegel deines echten Headsets wird in Echtzeit ausgewertet. Ein Panik-Schrei im echten Leben lockt den Stalker sofort an!

### 4. Anti-Clean Ästhetik & High-End PC DX12 Rendering
* **Lumen Hardware Raytracing:** Keine künstliche Dunkelheits-Aufhellung; unverbaute Räume sind 100% pechschwarz.
* **Substrate Multi-Layer Shaders:** Verrottetes Holz, abblätternder Lack, feuchter Schlamm (RVT) und samtige Schimmelsporen.
* **Bodycam / Found-Footage Post-Processing:** Dynamisches ISO-12800 Sensorrauschen, tonnenförmige Linsenverzerrung, chromatische Aberration und Lens-Dirt.

| **`[Tab]`** | Physischer Rucksack | Kniet sich ab & legt Rucksack auf Oberschenkel (Echtzeit-Verwundbarkeit) |
| **`[R]` (Klick)** | Nachladen | Magazinwechsel (langsame taktile Animation) |
| **`[R]` (Halten)** | Magazin-Inspektion | Magazin auswerfen und verbleibende Patronen visuell zählen |
| **`[M]`** | Topografische Karte | Hält Papierkarte mit markierten Landmarken & Baken ins Licht |
| **`[C]`** | Marschkompass | Hebt Kompass ins Sichtfeld für Azimut-Peilung |
| **`[T]`** | Wund-Inspektion | Hebt Arme zur Wundinspektion (Blutungen & Tourniquets anlegen) |
| **`[V]` (Halten)** | Proximity Voice | Diegetischer Funk / Direktsprache (wird von Monstern gehört!) |

## 🚀 DOWNLOAD & PLAY (GITHUB RELEASE STANDALONE)

Du musst die Unreal Engine **nicht** installiert haben, um das Spiel zu spielen!

1. Gehe auf die **[Releases-Seite](../../releases)** dieses Repositories.
2. Lade die neueste Datei herunter: `ProjectKrasnyBor_vX.X.X_Win64.zip`.
3. Entpacke das Archiv in einen beliebigen Ordner auf deinem PC (z.B. `C:/Games/KrasnyBor/`).
4. Starte **`KrasnyBor.exe`**.

### 👥 1–4 Spieler Multiplayer Schnellstart:
1. **Host:** Klicke im Hauptmenü auf **„Lobby Hosten“**.
2. **Mitspieler:** Klicken auf **„Lobby Beitreten“** oder treten direkt über die integrierte Steam-/EOS-Freundesliste bei.
3. **Kein Port-Forwarding nötig:** Das Spiel nutzt EOS P2P Relay für automatisches NAT-Punchthrough.

## 🛠️ DEVELOPER SETUP & BUILD FROM SOURCE

Wenn du als Entwickler am C++ Source Code oder den UE5 Assets mitarbeiten möchtest:

### 1. Voraussetzungen:
* **Unreal Engine 5.4.4** (über den Epic Games Launcher)
* **Visual Studio 2022** (mit den Workloads *Desktopentwicklung mit C++* und *Spieleentwicklung mit C++*)
* **Git** & **Git LFS** (Zwingend erforderlich für binäre `.uasset` und 3D-Dateien)

### 2. Repository Klonen:
```bash
# 1. Git LFS initialisieren
git lfs install

# 2. Repository mit LFS Assets klonen
git clone https://github.com/YourUsername/Project-Krasny-Bor.git
cd Project-Krasny-Bor

# 3. LFS Binärdateien nachladen
git lfs pull
```

### 3. Projekt Generieren & Kompilieren:
```bash
# Visual Studio Projektdateien generieren
./GenerateProjectFiles.bat

# Projekt in Visual Studio öffnen
start KrasnyBor.sln
```
* Stelle die Solution Configuration in Visual Studio auf **`Development Editor`** und die Plattform auf **`Win64`**.
* Drücke `F5`, um die Engine mit dem Projekt zu starten.

### 4. Standalone Packaging (.exe Build):
```bat
.\Engine\Build\BatchFiles\RunUAT.bat BuildCookRun ^
  -project="%CD%\KrasnyBor.uproject" ^
  -noP4 -clientconfig=Shipping -platform=Win64 -targetplatform=Win64 ^
  -build -cook -pak -stage -archive ^
  -archivedirectory="%CD%\Builds\Win64"
```
